# GalAxI Homebrew tap

Install and update the GalAxI macOS beta:

```bash
brew install --cask libertomed/galaxi/galaxi
brew upgrade --cask galaxi
```

The cask is updated automatically for each published release of
[libertomed/galaxi-dev](https://github.com/libertomed/galaxi-dev/releases).
The beta is not signed or notarized; see the cask caveats.
